# Design Patterns

A small .NET sample project demonstrating several structural design patterns with simple C# implementations.

## Implemented Patterns

This repository currently contains examples of the following structural design patterns:

- Decorator
- Facade
- Bridge
- Composite
- Flyweight

## Technologies

- .NET 9
- C#
- Console Application

## Project Structure

```text
DesignPatterns/
├── 01_Decorator
├── 02_Facade
├── 03_Bridge
├── 04_Composite
├── 05_Flyweights
└── Program.cs
```

## Run

From the repository root:

```bash
dotnet run --project DesignPatterns/DesignPatterns.csproj
```

The console application executes a small example for each implemented pattern.

## Build

```bash
dotnet build DesignPatterns.sln
```

## Purpose

This repository is intended as a learning and reference project for reviewing common design patterns and their basic implementation in C#.

The examples are intentionally lightweight and focus on demonstrating the structure and responsibility of each pattern.
